# cafe-landing

가상의 카페 "모닝빈"을 위한 간단한 단일 페이지 랜딩 페이지입니다. 빌드 도구 없이 HTML과 CSS만으로 만들었습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 소개, 오시는 길) |
| `style.css` | 스타일 (반응형 레이아웃, 카드 hover 효과) |

## 실행 방법

`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

## 수정 포인트

- 카페 이름, 메뉴, 가격, 주소와 영업시간은 `index.html`에서 바꿉니다.
- 색상과 배치는 `style.css`에서 바꿉니다.
